Start here

Two minutes on how the tracking works, so your notes end up where you expect them. Nothing to install and no account to create.

1Put your initials on it

At the top of the page there is Tracking as with a set of initials next to it. Everything you mark, rate or write is filed under whichever initials are showing.

The first time you open the site it asks for your initials — up to three letters. If you skipped that, or want to change them, press Rename. If someone else uses the same phone or laptop, press Add someone and they get their own set, kept completely separate from yours.

Initials are a label, not a password

Anyone holding this device can switch to your initials and read your notes. It keeps people sharing a device from overwriting each other; it does not keep secrets.

2Using it on more than one device

Your notes are stored in the browser you are using, so a phone and a laptop start out knowing nothing about each other. A sync code joins them up.

Two buttons, and it matters which device you press each one on.

On the device you have been using

Press My sync code. A panel opens showing a code like K7MP-2XQR-9TVB — twelve letters and numbers in three groups — with a Copy button. Press it again any time to see it.

Save that code somewhere other than this device, even if you never add a second one. It is the only way back to your notes if the phone is lost or replaced: nothing can look a code up for you.

On the device you are adding

Press Link a device and type that code in. Dashes and capitals do not matter. Your notes on this device are merged with the other device's, not replaced, and this device takes on the same initials — so if the first one says JRH, this one will too.

Both now show the same notes. After that it syncs by itself: when you open the page, a few seconds after you change something, or whenever you press Sync now.

Do not press My sync code on the second device

It would give that device a code of its own, and the two would go on tracking separately with no sign that anything was wrong. On the second device you want Link a device.

Nothing is lost when two devices disagree

If you marked a drink on your phone and rated it on your laptop, you end up with both. If you wrote a note in each place, you get both notes, not whichever synced last.

The code is the key — there is no password

Anyone who has your code can read and write your notes, from anywhere. It cannot be revoked or changed: a new code just starts you over somewhere else, and the old one keeps working for whoever has it.

Only share it with your own devices. And do not write anything in a note that you would mind a friend reading.

Each set of initials has its own code, so several people sharing a laptop sync to separate places.

3Tell it what you own

In the buying guide near the bottom, every bottle has an I have this checkbox. Tick the ones on your shelf and the panel near the top fills in: how many of the 52 you can make right now, and which ones are a single bottle short — naming the bottle.

Once you start marking drinks as made, those drop out of ready to make now and reappear below it under made before, ready again, so the top list is always the ones you have not poured yet.

Fresh things are assumed. It will not ask whether you have limes, sugar or eggs.

4Keep a copy

Once you have a sync code, your notes are already backed up: every change is sent to the server within a few seconds, and again whenever you open the page. A lost or replaced phone loses nothing, as long as you still have the code.

Download my notes also saves everything to a file, which is worth doing occasionally — it is the only copy that does not depend on the code. Restore from file reads one back and merges it with what is already there, so restoring never wipes anything.

Without a sync code, your notes live only in this browser, and clearing your browsing data would take them with it.

5If something looks wrong

  • Your notes vanished. Check the initials at the top first — you are probably looking at someone else's profile, or a renamed one.
  • You cleared your browser. Local notes are gone; restore from a downloaded file, or enter your sync code again to pull them back from your other device.
  • It says sync failed. Your notes on this device are untouched — the sync just has not happened. Press Sync now again in a minute. If the site has been quiet for a week the server may be waking up, which takes about half a minute.
  • Your other device shows nothing. Press My sync code on each and check they match. If they differ, you probably pressed My sync code on the second device instead of Link a device — press Link a device there and type in the first device's code. Nothing is lost either way; the two sets of notes merge when they meet.
